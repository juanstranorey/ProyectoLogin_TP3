## Descripcion
Proyecto de autenticacion y gestion de usuarios (Login y Registro) desarrollado de manera independiente con PHP 8, MySQL, HTML5, CSS3 y JavaScript.

## Instrucciones de Ejecucion
1. Clonar el repositorio dentro de la carpeta `htdocs` de XAMPP.
2. Iniciar Apache y MySQL en XAMPP.
3. Importar la base de datos `proyecto_login`.
4. Navegar a `http://localhost/ProyectoLogin_TP3/index.php`.
